# 🌾 SmartFarm — Farmer's Digital Assistant & Advisory Platform

An all-in-one, responsive, offline-capable digital agricultural assistant designed to empower farmers with precision agronomy, financial management, smart micro-irrigation, and market intelligence.

---

## 🌟 Modules & Features Breakdown

| Icon | Module | Core Functionality |
| :---: | :--- | :--- |
| 🏠 | **Home** | Farm overview, seasonal tip of the day, quick action tiles, and active crop progress preview. |
| 👨‍🌾 | **Registration & Login** | Multi-state farmer registration, profile credentials, farm acreage, and local session handling. |
| 📊 | **Farmer Dashboard** | Real-time KPI statistics, Chart.js crop distribution doughnut, expense breakdown, and tasks checklist. |
| 🌱 | **Crop Planner** | Sowing cycle planning, growth stage meter, harvest countdown timers, and crop rotation matrix. |
| 🌾 | **Crop Information** | 25+ Indian crops catalog with NPK ratios, cultivation guides, spacing, and 1-click planner import. |
| 💧 | **Smart Irrigation** | Water budget calculator, pump runtime scheduler, root-zone moisture simulator, and water-saving metrics. |
| ☁️ | **Weather Monitoring** | Real-time Open-Meteo weather API, 7-day agricultural forecast, and pesticide spray window advisory. |
| 🌍 | **Soil Monitoring** | Digital Soil Health Card, Soil Fertility Index (0-100), lime/gypsum/organic amendment recommendations. |
| 🧪 | **Fertilizer Reco.** | Scientific N-P-K balancer, Urea/DAP/MOP bag estimator, split dose timeline, and subsidized cost calculator. |
| 🐛 | **Pest & Disease** | 20+ pest/pathogen catalog with IPM organic remedies, calibrated chemical spray dosages, and instant diagnostic checker. |
| 💰 | **Market Prices** | Daily modal mandi rates across major APMCs, MSP 2025-26 benchmark comparison, and Sell vs Store advisor. |
| 💵 | **Expense Management**| Itemized cultivation cost tracking, category breakdown charts, target budget progress bar, and logs. |
| 📈 | **Profit Calculator** | Cost of cultivation vs gross revenue calculator, Net Profit, ROI %, break-even price, and side-by-side crop comparison. |
| 🚜 | **Farm Management** | Field parcel/plot subdivider, activity task scheduler with priority flags, and farm supplies inventory tracker. |
| 📊 | **Reports & Analytics**| Complete seasonal audit statements, monthly spending trends, printable report view, and CSV spreadsheet exports. |
| 🔔 | **Alerts & Notifications**| Automated harvest reminders, overdue task alerts, Kharif pest warnings, custom reminder creator, and sidebar badge. |
| 🚜 | **Farming Equipment** | 15+ agricultural machines & implements directory, operational specs, maintenance tips, and custom hiring rental estimator. |
| 🏛️ | **Govt Schemes** | 15+ Central & State schemes (PM-KISAN, PMFBY, KCC, PM-KUSUM, PKVY, SHC), eligibility wizard, and application checklists. |
| 🤖 | **Modern Technologies**| Precision AgriTech showcase (Drones, IoT, AI, Smart Drip, Hydroponics, Solar Pumps) with farm ROI payback calculator. |
| 📞 | **Contact Us** | Kisan Call Centre (1800-180-1551), emergency agricultural helplines, state department directory, and FAQ accordion. |
| ⚙️ | **Settings** | Farmer profile editor, dark mode theme toggle, unit selection, and 1-click sample demo data loader. |

## 🚀 How to Run

### Method 1: Double-Click
Simply double-click [`run.bat`](file:///C:/Users/T%20Narasimha%20Reddy/.gemini/antigravity/scratch/smart-farm-app/run.bat) in the project folder. It will launch a local server and open your default browser to `http://localhost:8080`.

### Method 2: Command Line
```powershell
cd "C:\Users\T Narasimha Reddy\.gemini\antigravity\scratch\smart-farm-app"
py -m http.server 8080
```
Then visit [http://localhost:8080](http://localhost:8080) in your web browser.

### Method 3: Direct File Open
You can also directly double-click `index.html` to run in your browser. All core modules, local storage persistence, and calculators will function without any server requirements.
